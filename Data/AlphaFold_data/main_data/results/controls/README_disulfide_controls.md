# Disulfide-augmentation controls (revision)

Robustness checks for the disulfide-augmented persistent-homology result.
All on the Cα representation (the disulfide staple is a Cα-pair operation), on the
747-protein `has_ss` subsample. Generated by the scripts in
`scripts/computation/`: `disulfide_cutoff_sweep.jl`,
`disulfide_random_staple_control.jl`, `disulfide_full_filtration.jl`.

## Files
- **plain_cutoff_sweep_h1med.csv** — per-protein plain H1 median persistence at
  Vietoris–Rips cutoffs 8/10/12/14/16/20 Å.
- **disulfide_cutoff_sweep.csv** — R²_family|size of plain persistence at each
  cutoff. Signal is flat (0.61→0.59 over 8–20 Å); 12 Å is numerically identical
  to the full untruncated filtration (all Cα loops close within 12 Å), so the
  cutoff does not affect the result.
- **disulfide_random_staple_h1med.csv** — per-protein H1 median persistence when
  the same number of *random, non-bonded* Cα pairs (matched to each real bond's
  sequence separation) are stapled to ~0. 20 seeds.
- **disulfide_control_pooled.csv** — pooled R²_family|size: plain 0.596,
  disulfide-augmented 0.700, **random matched staple 0.668 ± 0.003**. So ~70 % of
  the augmentation gain (+0.073) is a generic staple effect and only +0.031 is
  disulfide-specific.
- **disulfide_control_perfamily.csv** — per-family plain/augmented/random median
  persistence and the control-adjusted excess (augmented − random). The excess CI
  excludes zero and is positive **only for 3FTx**; all other families are ≤ 0.

## Take-away
The between-family gain from disulfide augmentation is largely a generic
consequence of stapling; the disulfide-specific residual is small and confined to
3FTx, and it does not reproduce on the experimental set (0.45→0.43). The plain
Cα persistence signal itself is robust to the filtration cutoff.
